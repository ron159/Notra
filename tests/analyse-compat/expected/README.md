# Expected Results

Structured expected output generated by the frozen AnalysePlugin/Notepad++
binary Oracle belongs here. The environment and its hashes are Release evidence,
not a development-phase gate.

Files marked `provisional_not_binary_verified` are deterministic Notra core
contracts, not binary compatibility proof. They keep the functional harness
executable while the Windows Oracle is unavailable. Recorded Oracle output later
produces a difference report; only function-blocking differences fail the
Release gate.
